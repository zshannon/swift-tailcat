Lists preserve absent versus empty semantics. A nil `allowedClients` list permits anyone who knows the Tailcat credential; a nil `allowedProxies` list permits any destination when forwarding is enabled. An empty list denies the corresponding client or destination access. These lists govern permission and do not enable forwarding by themselves. Nil served-port lists defer to handlers; empty lists filter all direct ports except active listeners. Supplied policy callbacks replace list decisions; revoked keys remain denied. Assign `Tailcat.Server.Configuration.handlers` and `.policy` before `makeServer(configuration:)`; both are mutable configuration properties. Configuration and handlers are installed before startup. Selection receives a `Tailcat.Server.Offer` with transport, destination, and whether forwarding is requested; callbacks decline before acceptance when no handler exists.

## Test scope

Swift uses Swift Testing, not XCTest. `ValueTests.swift` covers values, continuation races, runtime cancellation/close, nil byte decoding, authentication distinction, key sources, and explicit storage. The fixture-enabled `LoopbackTests` and its extensions cover encrypted TCP/UDP, IPv6 generic dial/listen, authenticated peer metadata, half-close, close/cancellation, handler cancellation, child ownership, admission/cache isolation, native SSH/SFTP, recursive metadata-preserving transfer, chunked write-only uploads, anonymous SSH/DNS safety, SOCKS local command cancellation, callback/logging behavior and short owned-relay perf/progress. `Scripts/test-swift.sh` supplies the fixture and isolated home; ordinary `swift test` skips this suite when `TAILCAT_FIXTURE_BIN` is absent.

Bridge tests add custom callbacks/listener override, dynamic revocation, empty UDP packets, deadlines, exit forwarding, SOCKS TCP/UDP, DERP cache revalidation/stale fallback, owned DNS TXT, anonymous SSH, all file modes and confinement, local managed process/PTY cleanup, and live/bounded progress. Use `Scripts/test-go.sh` for the bridge race suite; `Scripts/check-platforms.sh` and `Scripts/verify-artifact.py` check the built slices and archive.

Runtime verification is macOS arm64 only. iOS device/simulator execution, macOS x86_64 execution, internet NAT traversal, stock `tailcat` modes beyond stream mode, OpenSSH interoperability, external key-source accounts, and production throughput remain unverified.
