# Internal mobile protocol v1

This is the internal Swift-to-Go adapter reference. App consumers use the [README](../../README.md) and [typed request guide](../../Docs/Messaging.md). Typed request frames have a separate [wire reference](../../Docs/MessagingWire.md).

The sole transport is `NewRuntime`, `Runtime.NewOperation`, `Operation.Begin(method,input,Completion)`, `Operation.Cancel`, and `Runtime.Close`. `Completion.Complete(result,code,message)` occurs exactly once on a Go goroutine. JSON object input is required. Errors: 0 success; 1 invalid input; 2 cancellation; 3 closed; 4 unsupported capability; 5 upstream/I/O failure. Bytes use standard base64 JSON strings, times/durations are integer nanoseconds. Resource IDs are opaque positive signed 64-bit integers owned by one runtime. `resource.close` closes descendants; runtime close cancels operations and releases resources.

`Policy.AllowClient(key string) bool` and `Policy.AllowProxy(endpoint string) bool` are synchronous callbacks. Install via `Runtime.SetPolicy(serverHandle int64, policy Policy) error` before startup. Nil callback means default policy. Callback must not synchronously wait on an actor currently awaiting bridge work.

Common input fields: `handle`, `parent`, `address`, `network`, `port`, `data`, `count`, `readDeadline`, `writeDeadline`. Handle creation returns `{handle}`. Resource operations return `{}` unless described below. Connection reads return `{data,eof,address?}`; writes return `{count}`; address returns `{local,remote}`; listener creation/inspection `{handle,address}`.

A successful zero-length UDP read returns `{data:"",eof:false,address?}`. It remains a datagram and does not end the stream. Both connected and packet reads enforce revocation for empty datagrams. Guard installation after the engine accepted a flow fails closed if its peer metadata was already removed. Client drain before successful startup is a no-op because no TCP endpoints exist; cancelling an active drain preserves its sockets.

## Methods

- `capabilities`: `{processExecution,sshServer,maxUDPPayload,defaultUDPIdleTimeout,upstreamRevision}`.
- `address.parse`, `address.raw`, `address.resolve`: `{address,derpMapURL?,cache?,forServer?}`; parse returns upstream ConnInfo JSON; raw preserves decoded unknown wire fields; resolve returns `{address}`.
- `address.encode`: `{info: <upstream ConnInfo JSON>}` → `{address}`.
- `identity.generate`, `identity.import`: import `{identity:<upstream PrivateKey JSON>}` → upstream PrivateKey JSON (host explicitly stores it).
- `key.public`, `key.disco`: `{privateKey}` → `{key,data}`; `key.preshared`: optional `{data}` or `{key}` → `{key,data,isZero}`.
- `derp.fetch`, `derp.pick`: `{derpMapURL?,cache?}` or `{map}` → upstream full map / `{region}`. `cache.create`; `cache.get` `{handle,url}` → `{data,etag,storedAt,ok}`; `cache.put` `{handle,url,data,etag,storedAt?}`.
- `server.create`: `{privateKey?,presharedKey?,disablePresharedKey?,region?,regionID?,derpMapURL?,cache?,allowedClients?:[key],allowedProxies?:[endpoint],servedTCPPorts?:[{first,last}],servedUDPPorts?:[{first,last}],udpIdleTimeout?,exitNode?}`. Absent arrays retain upstream nil semantics; empty arrays deny all.
- `server.start`, `server.address`, `server.status`, `server.drain`: `{handle}`; address returns `{address,ip}`; status preserves all upstream fields.
- `server.listen`: `{handle,network,address}` → `{handle,address}`. `listener.accept`: `{handle}` → `{handle,local,remote}`.
- `server.admit`, `server.revoke`, `server.contains`, `server.disconnect`: `{handle,key}` → `{allowed}` / `{disconnected}`. Revoke removes key first and disconnects it.
- `server.peer`: `{handle,address}` → `{key,ok}`; `server.peerEnvironment`: `{handle,local,remote}` → `{environment}`.
- `client.create`: `{address,privateKey?,derpMapURL?,cache?}`. `client.key` → `{key}`; `client.region` → upstream region; `client.ping` and `client.discoPing` → complete upstream result; `client.drain`.
- `client.dial`: `{handle,network,address}`; `client.dialPort`: `{handle,network,port}`; `client.dialEndpoint`: `{handle,network,address}` → `{handle,local,remote}`.
- `connection.read`, `connection.readPacket`: `{handle,count}`. `connection.write`, `connection.writePacket`: `{handle,data,address?}`. `connection.address`; `connection.deadline` `{handle,readDeadline?,writeDeadline?}` (Unix nanoseconds; zero clears); `connection.closeWrite`; `connection.proxy` `{handle,other,packet?}`.
- `forward.start`: `{handle,bind,network,port?,address?}` → `{handle,address,url?}` (client parent, multiple independently closable listeners). `socks.start`: `{handle,bind}` → `{handle,address}`.
- `server.service`: `{handle,port,kind,exec?,ssh?,maxStreams?,maxDuration?}`. kind `exec`, `ssh`, `perf`. SSH options `{shell,exec,authorizedKeys,files:{dir,mode}}` follow upstream semantics. Exec/shell/forced commands explicitly reject iOS; SSH/SFTP protocol remains available.
- `ssh.validateKeys`: `{keys:[text]}`. `ssh.connect`: `{handle,port,user,privateKeys?,hostKey?}` → `{handle,hostKey}`. Host key is required; no silent trust bypass. `ssh.run`: `{handle,command,input?}` → `{stdout,stderr,exitCode}`. `ssh.session`: `{handle,pty?:{term,width,height}}` → `{handle}`; `ssh.session.start` `{handle,command?}`; `ssh.session.read/write/wait/resize`.
- `sftp.connect`: `{handle}` (SSH parent) → `{handle}`. `sftp.list/stat/lstat/read/write/mkdir/remove/rename/chmod/times`: `{handle,path,...}`; list/stat/lstat return file metadata, reads `{data}`, writes `{count}`. `lstat` preserves symbolic-link mode without following its target. File timestamps are Unix nanoseconds. `sftp.read` accepts offset/count; `sftp.write` accepts offset/data/create/truncate; rooted server supplies confinement.
- `perf.run`: `{handle,params:<official perf Params JSON>,allowSharedRelay?:false,requireDirect?:false}` → full official Result with `progress` snapshots.
- `resource.close`: `{handle}`.

Cancellation closes accepted/dialed resources that lose the completion race. Cancelling I/O applies a directional deadline; cancelling accept closes that listener. Resource and runtime close are idempotent. One read and one write may run concurrently per connection; overlapping reads or writes are rejected. Future unknown method names return unsupported.

SSH/SFTP operations install their cancellation hook before blocking channel, PTY, or subsystem requests. Cancelling `ssh.run`, `ssh.session` creation, any `ssh.session.*` operation, `sftp.connect`, any `sftp.*` operation, or persistent file I/O invalidates the owning SSH transport and all sibling SFTP/session/file handles. This scope is required to unblock stalled peer replies and upstream file locks. Ordinary successful persistent-file `resource.close` closes only that file and preserves its SFTP/SSH parent; cancelling a stalled file close interrupts the SSH transport. Explicit SFTP-client close also invalidates its owning SSH subtree. SSH/SFTP parent/runtime shutdown interrupts transports before joining file I/O or remote CLOSE acknowledgments.

`ssh.session.wait` executes the upstream one-shot Wait once and caches its result; simultaneous and later waits receive that same result while the session remains open. PTY window changes are coalesced without blocking exec/shell startup, including changes before start. Resource close calls joining an already-closing handle or ancestor wait for the shared cleanup completion, including cleanup initiated by runtime close; cancellation before `resource.close` begins or during its execution still performs/joins cleanup and reports the actual cleanup result. Cancellation continues to interrupt transports, but does not replace a successful cleanup or a genuine cleanup failure with the operation cancellation signal.

Additional value methods: `address.expand` takes `{info,map?,derpMapURL?,cache?,forServer?}` and returns expanded upstream ConnInfo; `key.node` and `key.discovery` take `{key}` or `{data}` and return `{key,data}`. `disco.encodePing` takes `{key,discoKey}` → `{data}`; `disco.parsePing` takes `{data}` → `{key,discoKey,ok}`; `disco.encodePong` → `{data}`; `disco.inspect` → `{isMeow,isMeowed}`. `server.service` for SSH additionally returns the public OpenSSH `hostKey`, enabling explicit client pinning. Official perf direction values are `up`, `down`, `both`.

## Callback and lifetime refinements

`Handler.Select(network,destination string,forwarded bool) bool` selects an upstream handler before acceptance. Direct destinations are `:port`; forwarded destinations are the normalized IP:port (including IPv4 decoded from NAT64). False or a recoverable callback panic returns a nil upstream factory, producing TCP rejection/UDP drop. `Handler.Connection(handle int64,network,local,remote string,forwarded bool) bool` then delivers an owned accepted connection; false/panic closes it. Install via `Runtime.SetHandler(serverHandle int64,handler Handler) error` before startup; active listeners override these hooks.

After Connection returns true, the Go factory remains alive until its owned connection closes, preserving netstack's forwarded-destination routing while Swift handles the connection asynchronously. Native forwarding factories likewise remain alive until their proxy worker finishes.

`Logger.Log(handle int64,message string)` receives formatted instance logs; `Runtime.SetLogger(handle int64,logger Logger) error` installs it for a server/client. `Runtime.ConfigureVerbose(verbose bool) error` sets upstream process verbosity before its first network/DERP use; it freezes thereafter. Callbacks run without bridge locks, must return promptly, and must not synchronously close their own runtime/resource (close waits for callbacks).

`Progress.Update(result string)` receives live official perf Progress JSON. Install using `Operation.SetProgress(progress Progress) error` before Begin. Perf completion waits for admitted progress callbacks and releases the callback reference. Final progress retains the newest 1024 samples in order and reports `progressDropped`.

Accepted raw TCP/UDP listener connections belong to their server: closing a listener stops accepts while preserving accepted connections. Closing server/runtime closes them. Services own their active sessions. Resource close cancels and waits for operations referencing that resource or a closed descendant. The adapter suppresses incoming/outgoing data on server-owned flows after their authenticated peer is removed, addressing retained established flows in the pinned upstream; sockets retain deadline/cancellation behavior instead of being reset.

## Additional CLI/file operations

- `address.lookup`: `{name,resolver?}` → `{address,dnsName}`. Resolver is an explicit host:port for host-selected/local DNS. Secret Tailcat-address labels are rejected before any DNS query; `tailcat=` TXT contents are validated.
- `ssh.connect` accepts optional endpoint `address` alongside server `port`. `ssh.probeAnonymous`: `{handle,port?,address?,hostKey,user}` → `{accessible}`. It uses a fresh node identity and no SSH credentials, pins the supplied host key, sends no command/PTY request, and releases its temporary client.
- `ssh.session.closeInput`: `{handle}` sends stdin EOF. Reads and writes reject overlap within their direction.
- `socks.command`: `{handle,exec:[program,args...],environment?:{name:value}}` → `{stdout,stderr,exitCode}`. macOS only; sets upper/lower-case ALL_PROXY/HTTP_PROXY/HTTPS_PROXY to its SOCKS endpoint. Operation cancellation, service close and runtime close terminate the owned process group.
- `sftp.open`: `{handle,path,write?,create?,truncate?}` → `{handle}`. `sftp.file.read`: `{handle,offset,count}` → `{data,eof}`. `sftp.file.write`: `{handle,offset,data}` → `{count}`. `sftp.file.stat`: `{handle}` → file metadata. Close the persistent file with `resource.close`; use one handle for every chunk of a write-only drop-box upload so collision naming occurs once.
- `server.forward`: `{handle,port,network,address}` → `{handle,address,port}`. Network is `tcp` or `udp`; destination address is an explicit hostname/IP and port. Port zero chooses an unused Tailcat listener port. The result address is the Tailcat listener IP:port. The service owns its listener, accepted flows, native destination sockets and cancellable native dials; closing service/server/runtime releases them. TCP half-close and complete UDP datagrams, including empty datagrams, are preserved.
- `server.create` accepts optional `localPortHost`, a hostname or IP without a port (bracketed IPv6 is accepted). It explicitly enables same-port direct TCP/UDP forwarding to that host; served-port filters still apply and active listeners override it. A nonnil Handler replaces these default callbacks; SetHandler(nil) restores them. The host is never implicitly enabled. Exit-node forwarding also owns its native sockets and pending dials.

## Injectable DERP cache

`CacheStorage.Get(url string) string` returns JSON `{data,etag,storedAt,ok}` or an empty string for a miss. `data` is base64 (null is empty bytes), `etag` is opaque, `storedAt` is Unix nanoseconds, and `ok` is boolean. Missing required fields, malformed JSON/base64 and recoverable Get panics are misses. `CacheStorage.Put(url,entry string) string` receives the same JSON and returns an empty string on success or an error message. Explicit `cache.put` propagates write failures/panics; official `FetchDERPMap` continues to ignore Put errors, preserve ETag revalidation, renew freshness after 304 and fall back to stale maps.

Install using `Runtime.SetCacheStorage(cacheHandle int64,storage CacheStorage) error` before the cache's first direct operation or attachment to a consumer. Nil preserves memory storage. Admission and callback reference capture occur under the cache lock, then user code runs with no bridge lock held. Cache/runtime close prevents new callbacks and joins every admitted callback before returning. Existing consumers of a closed cache see a miss; direct closed handle operations fail closed. Callbacks must return promptly and must not synchronously close their own resource/runtime, because close waits for them. Swift clients and servers retain their configured cache resource.

`cache.put` accepts optional `storedAt`; absence uses the current timestamp, while an explicit zero means the Unix epoch. `address.resolve` accepts an explicit `map` with region/node validation. `derp.fetch` accepts `forServer` to emit the upstream server map hint. Generic `client.dial` delegates all six upstream networks (`tcp`, `tcp4`, `tcp6`, `udp`, `udp4`, `udp6`) and host/service resolution; endpoint dialing retains numeric IP:port parsing. Upstream server listening supports only `tcp`, `tcp6`, `udp`, `udp6` and uses service-name lookup (such as `:http`).
